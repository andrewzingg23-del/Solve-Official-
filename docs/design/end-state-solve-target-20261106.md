# SOLVE end-state visual references: one engine, distinctive personal Spaces

**Status:** Product visual target, not a record of production functionality.

## Source references (shared in the founder conversation, November 6, 2026)

1. **SOLVE · One Setup. A Space That's Yours.** Dark graphite and silver UI, SOLVE ring wordmark, Meet AI → Context → Build → Your Space, and three distinct outcomes: operator, gamer/creator and household. Integrations are recognizable brands, not generic abstractions.
2. **Avery's expressive, media-rich Space.** A creative environment with a personalized atmosphere, connected services, projects, communications and media. This is the desired upper limit of personalization, *not* a mandate to show photographs, invented accounts, dummy transactions or fictional status on first login.

The images are visual references provided in conversation; personal photographs are not checked into source control.

## Core implementation rules

- **One system:** A shared navigation shell, typography scale, spacing and glass/material tokens. Product name SOLVE; SOV ID is identity.
- **Many expressions:** Selected interests compose different landing actions, card order and suggested provider surfaces. The first selected focus determines the initial arrangement. People can later modify it.
- **Optional atmosphere:** Neutral graphite is the clean default. Warm, cool or creative ambience is selected explicitly through approved appearance settings, not forced onto everyone.
- **Reality over theater:** Tasks, revenue, calendar, finance charts, devices, active agents, communities, notifications and connected accounts must be backed by real authorized data before displayed as live.
- **Recognition matters:** Show provider names in a familiar dock. An app selection is **not** a connected account. A public YouTube/Spotify embed is **not** OAuth and does not authorize data access.
- **Public by intent only:** Private Space, public SOV Profile and shared Worlds are separate permission boundaries. Imported notes and personal-context interviews stay private.
- **Agent personalization:** A style request yields a validated preview. Apply, discard and undo are explicit. No generated arbitrary CSS/HTML, scripts or permission changes.
- **Adaptation:** Phone layout remains navigable at small widths with touch targets and readable text. Reduced-motion preference is respected.
- **External use:** The SOV ID and shareable creations should remain useful even if a visitor never creates a SOLVE account.

## Current scope, deliberately narrower than the references

Implemented: focus-composed cockpit, real project readback where available, safe appearance settings, selected-app dock, provider-hosted public-media widget after an explicit interaction, existing AI chat in the follow-up branch.

Not yet represented as live: arbitrary widget editor, account-linked streams for calendar/email/finance, provider OAuth for the broader app dock, immersive 3D/photographic themes, publishing the public SOV Profile, device operation and real-time collaboration guarantees.

## Acceptance scenarios

1. A person who chooses business first sees work/projects early; a person who chooses gaming or music sees creation/community first; a family-first person sees people/privacy first. No fabricated counters or activity.
2. Guests can complete the flow and return to a local Space; signed-in users retain authorized preferences across devices.
3. The app dock displays provider names, capability/setup state and truthful authorization labels. Selected ≠ Connected.
4. A user can paste a public Spotify/YouTube URL, explicitly load its provider-hosted player, save/remove the canonical link and reload without needing account OAuth.
5. The same URL input rejects unsafe/unsupported hosts and cannot inject HTML, CSS, script or private network requests.
6. Public-facing profile is not updated or published by changes to appearance, private context, media or integrations.
7. New functionality routes only to production-available pages. Experimental URLs do not become broken core shortcuts.
8. Visuals remain recognizable as SOLVE across all four personas and on mobile, even when the content and atmosphere differ.
